# Modelagem-de-Otimiza-o-do-Sistema-Educacional
Trabalho de Matemática Discreta do grupo: Leonardo Ruiz, Caroline Chamon, Eduardo Pina, Maximus Campero

O objetivo do trabalho é classificar os professores por sua titulação, sendo a pontuação mais alta o Doutorado (10 pontos) e a posição mais baixa Ensino Médio (1 ponto).
Com todos os professores classificados, realocamos a distribuição deles a fim de diminuir as discrepâncias e maximizar o índice de qualidade geral da escola com a pior situação educacional.
